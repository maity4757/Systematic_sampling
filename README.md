# Systematic_sampling

This project is an interactive R Shiny application that demonstrates systematic sampling design for estimating a population mean. The app calculates the required sample size based on allowable error, bias, and confidence level, performs optimal allocation across subgroups considering variance, cost, and time, and applies systematic sampling within each subgroup. A graphical visualization highlights population units and selected samples, making the tool especially useful for learning, teaching, and experimenting with sampling techniques.
